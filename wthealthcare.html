West Tennessee Healthcare

2019-Current | Interactive team at The Johnson Group

I currently design and build out web pages for West Tennessee Healthcare, initially using Sketch but now design them in Figma. I build out the pages in Wordpress using a CMS built by the team at The Johnson Group. Using the existing brand formatting and design, each page presents a new challenge in implementing written content, imagery, and extras such as service-specific subpages and interactive content.

Swiftly learning how to use Facebook’s software for creating dimensional and interactive photo filters, I was able to create a filter for “No Shave November” for WTH during November of 2019 to raise awareness for men’s health. I created vector moustaches and brought them into Spark AR.
